# 文字サーキットレース

好きな1文字を、タイヤ付きの「文字そのものの車体」にして競う見下ろし型2Dレースゲームです。スマートフォン縦画面・PCブラウザ対応。インストール不要で、外部素材・外部ライブラリ・ビルド工程・サーバー処理はありません。

## 遊び方

1. ひらがな・カタカナ・漢字・英数字・記号などから、好きな**1文字**を入力します。
2. 車体カラーを選び、プレビューと **SPEED / ACCEL / STABILITY / WEIGHT** を確認します。
3. **START**でCPU3台との3周レース開始。車は自動走行します。
4. レース中に**画面をタップ**、または **BOOST** ボタンで加速！ 使用できるのは1レース3回です。PCではスペースキーも使えます。
5. 青い床はスピードアップ、茶色い床はスローダウン。コースは3種類から毎レース抽選されます。
6. ゴール後に順位・タイム・ベストラップを確認できます。歴代BEST LAPはブラウザのlocalStorageに保存されます。

初期設定はミュートです。画面内の 🔇 / 🔊 ボタンで効果音を切り替えられます。

## 文字の性能と当たり判定

入力文字はCanvasで実際に描画し、アルファ画素から**実描画範囲・ピクセル面積・重心の偏り・左右対称性・輪郭・形状の複雑さ**を計測します。これらから車両性能を算出し、CPUにも同じ計算方法を使用します。壁との接触には文字輪郭上の点、他車との接触には実際の文字の不透明ピクセルを使います。共通の長方形シャーシの当たり判定ではありません。環境の日本語フォントによって文字の見た目と計測結果が多少変わることがあります。

## GitHub Pagesへの配置

1. `index.html`、`style.css`、`game.js`、`README.md` を**同じ階層**に配置します。
2. GitHubリポジトリの `main` ブランチにアップロードします。
3. GitHubの **Settings → Pages → Build and deployment** で **Deploy from a branch**、`main`、`/(root)` を選択して保存します。
4. 公開URLへアクセスして遊びます。`index.html` をPCで直接開くこともできます。
